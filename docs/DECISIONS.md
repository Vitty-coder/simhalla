# DECISIONS — Registro de decisiones técnicas

Formato: **ID · estado · decisión · motivo · dónde cambiarla**.
Estados: `adoptada` (técnica, estable), `provisional` (punto abierto de
PROJECT.md §21 resuelto con el valor más simple; revisable), `pendiente` (no
decidida; ver ROADMAP). Ninguna decisión elimina o sustituye un requisito
confirmado de PROJECT.md.
