# TESTING — Pruebas, comandos y criterios

## Ejecutar la suite (headless, sin dependencias externas)
```bash
tools/run_tests.sh              # toda la suite
tools/run_tests.sh damage       # solo ficheros cuyo nombre contenga "damage"
GODOT=/ruta/a/godot tools/run_tests.sh
```
Equivale a `godot --headless --path . --import` (reconstruye la caché de clases globales; necesario la primera vez o al añadir clases) y `godot --headless --path . --script res://tests/run_tests.gd -- [filtro]`. Código de salida 0 = todo OK, 1 = fallos.

Marco propio mínimo (`tests/test_case.gd`, decisión D-025): cada `tests/{unit,integration}/test_*.gd` extiende `TestCase`; cada método `test_*` es un caso. Helpers: `assert_true/false/eq/ne/almost/contains`, `make_entity`, `make_engine`.

## Android (comprobación de humo, D-027)
`export_presets.cfg` define un preset *Android* (arm64, sin Gradle). Requiere plantillas de exportación 4.7.2, SDK de Android y un JDK. Sin tocar la configuración global del editor puede usarse un `XDG_CONFIG_HOME` temporal con `editor_settings-4.7.tres` que apunte al SDK/JDK/keystore:
```
XDG_CONFIG_HOME=<dir> godot --headless --path . --export-debug Android build/simhalla-debug.apk
```
Resultado verificado: APK debug de ≈ 28 MB exportado y firmado. **No se ha ejecutado en un dispositivo** (pendiente: correr la suite/duelo en Android y comparar huellas con PC).
